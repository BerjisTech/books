Books is a platform where authors and publishers collaborate to distribute their work primarily online.

Core ideas

- Author/publisher collaboration: upcoming authors can attract publishers; publishers can scout authors.
- Reader marketplace: buy ebooks and, where allowed, share via controlled links; option to buy hard copies.
- Book clubs: create or join clubs, chat in rooms, and discuss books.
- Meetups: organizers (authors, publishers, clubs) can host free or paid physical meetups; readers can discover and register.

Deliverables

- Angular frontend (SPA) under `books/frontend`.
- Go service backend under `books/service` with Postgres and migrations.

Next steps

- Integrate with Core API (auth, billing) and add UI flows for marketplace, clubs, and meetups.
